# Historical Audit Documents Index

> [!IMPORTANT]
> **These documents represent in-sample or historical analyses only.** They were generated before the strict chronological out-of-sample validation protocol was established. Do not use them as evidence of live or out-of-sample performance. The authoritative performance evaluation is in [`docs/OUT_OF_SAMPLE_RESULTS.md`](file:///c:/SC_results_WF/docs/OUT_OF_SAMPLE_RESULTS.md).
