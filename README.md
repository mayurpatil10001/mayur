# Sierra Chart Trade Optimization Platform

> **A full-stack trading analytics platform** that parses Sierra Chart binary trade logs into a SQLite database and applies statistical filtering (Benjamini-Hochberg FDR correction) to identify time-of-day trading edge.

---

## ⚠️ Out-of-Sample Verdict: INCONCLUSIVE (Negative PnL OOS)

> [!IMPORTANT]
> **The headline metric is the out-of-sample result, not the in-sample result.**
>
> In-sample (training window `2023-09-04 to 2024-12-31`), the BH-FDR filtered pipeline shows **+$676k profit** on 6,332 trades vs. -$4.77M baseline — a compelling improvement.
>
> **However**, when the frozen slot criteria are applied to the strictly held-out out-of-sample test window (`2025-01-01 to 2025-10-31`) — data the selection pipeline never saw — the result is **-$117,987 loss** on 383 trades, with a Profit Factor of **0.79** and Sharpe Ratio of **-0.88**.
>
> **Plain-language verdict: The strategy does NOT demonstrate a statistically defensible out-of-sample trading edge as of this audit (July 2026).**
>
> The in-sample improvement is partially attributable to multiple-comparisons fitting across 5,472+ candidate slots. The permutation test confirms that pure noise data produces profitable-looking in-sample selections on average, and the strategy's out-of-sample performance is consistent with non-stationarity / regime change rather than genuine predictive edge.
>
> Full details in [`docs/OUT_OF_SAMPLE_RESULTS.md`](docs/OUT_OF_SAMPLE_RESULTS.md) and [`docs/PERMUTATION_TEST_RESULTS.md`](docs/PERMUTATION_TEST_RESULTS.md).

## Permutation Test (Null Distribution, 1,000 Iterations)

Generated by `python scripts/run_permutation_test.py` with `--seed=42` (fully reproducible).

| Metric | Real In-Sample Result | Null Mean ($H_0$) | Null 95th Percentile | Null Max (Pure Noise) | Empirical $p$-value |
| :--- | ---: | ---: | ---: | ---: | ---: |
| **Realized PnL ($)** | $944,400.35 | $261,925.88 | $436,442.19 | $705,252.87 | **0.0000** |
| **Win Rate (%)** | 62.60% | 59.86% | 61.75% | 65.87% | **0.0190** |
| **Profit Factor** | 2.14 | 1.53 | 1.85 | 2.21 | **0.0030** |
| **Selected Slots** | 39 | 17.0 | 24 | 29 | — |

**Key finding:** The in-sample result IS statistically distinguishable from pure noise (empirical $p < 0.05$ on PnL and profit factor). However, the out-of-sample result shows severe performance decay, consistent with non-stationarity of the underlying strategies rather than a genuine persistent edge.

> **Caveat:** Under pure noise ($H_0$), the BH-FDR selection pipeline still discovers an average of **17 slots with $261k in false-positive in-sample PnL** due to multiple-comparisons overfitting. Time-of-day slot independence is violated across correlated equity futures, inflating the effective false discovery rate above the nominal $Q=0.05$.

## How to Run

### Quick Start (Windows)
```cmd
START.bat
```
Starts backend on `http://localhost:8000` and frontend on `http://localhost:3000`.

### Manual Setup
```bash
cp .env.example .env
pip install -r requirements.txt
python main.py           # Backend: http://localhost:8000/docs
cd frontend && npm install && npm start  # Frontend: http://localhost:3000
```

### Docker
```bash
docker-compose up --build
```

### Reproduce the Audit
```bash
# Out-of-sample performance audit (train/test split, frozen slots)
python scripts/run_out_of_sample_audit.py
# → outputs docs/OUT_OF_SAMPLE_RESULTS.md

# 1,000-iteration permutation/shuffle test (null distribution)
python scripts/run_permutation_test.py
# → outputs docs/PERMUTATION_TEST_RESULTS.md
```

## System Architecture

```text
Sierra Chart (.data binary files in dataset/)
        │
        ▼
[BinaryLogParser — binary_log_parser.py]
- Multi-threaded TLV binary reader
- Ghost fill sequence resynchronization (purges orphaned open_legs on ghost exit)
- Session boundary filter (drops trades crossing 17:00 NY close)
- ParentInternalOrderID pairing + FIFO fallback
        │
        ▼ writes to processed_trades (SQLite, 126,991 clean trades)
[FastAPI Backend :8000] ←→ [React+TypeScript Dashboard :3000]
```

## Security

- All credentials (SECRET_KEY, DATABASE_URL, API keys) are in `.env` — **never committed**.
- `.gitignore` explicitly excludes `.env`, `dataset/`, `*.db`, `*.log`.
- JWT authentication (30-min expiry). Set `DEVELOPMENT_MODE=false` in production.
- Rate limiting: 500 req/min. Restrict `ALLOWED_ORIGINS` in production.
